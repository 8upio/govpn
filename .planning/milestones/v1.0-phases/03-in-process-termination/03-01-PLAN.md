## D-13 resolved: one package, not `netstack` + `netstack/tcp`

RESEARCH.md's Recommended Project Structure suggests a `netstack/tcp/` subpackage. D-13
leaves this to implementation discretion, and this phase resolves it as **a single package
`netstack`** with file-level separation (`stack.go`, `ipv4.go`, `icmp.go`, `udp.go`,
`tcp_segment.go`, `tcp_state.go`, `tcp_conn.go`, `tcp_listener.go`, `tcp_timer.go`).

Reason: a `netstack/tcp` subpackage would force exporting the IPv4 builder, the RFC 1071
checksum, the pseudo-header sum, the deadline timer, and the per-attachment write path
across a package boundary that exists only for file organization — five new exported
symbols with no external consumer. File-level separation gives the same per-file test
isolation with none of that surface. Every file still carries its own RFC citation header
per `internal/wire`'s convention.

**`netstack/stack.go`.** Declare the local session interface (D-18, RESEARCH.md
Pattern 5):

`Session` is the interface `Attach` accepts — `Read(p []byte) (int, error)`,
`Write(p []byte) (int, error)`, `Close() error`, i.e. exactly `io.ReadWriteCloser`.
Document that `Read` is datagram-shaped (one full IP packet per call), that it is called
from exactly one goroutine, and that `Write` may be called concurrently from many
(RESEARCH.md Pattern 4 verified this against `internal/datachan.Wrapper.Seal`'s own
mutex). The assigned tunnel IP is NOT read off the session — it is passed to `Attach`, so
this interface stays free of any `ovpn`-specific method.

`Stack` carries: the server tunnel IP as a `netip.Addr`; `mu sync.RWMutex` guarding
`routes map[netip.Addr]*attachment`; the two protocol-handler seam fields described
below; a `stats` struct of `atomic.Uint64` counters; `stopCh`/`stopOnce` for `Close`.

`New(serverIP net.IP, opts ...Option) (*Stack, error)` validates that `serverIP` is a
non-nil IPv4 address (reject IPv6 and nil with a typed error — D-17) and returns the
stack. `Option` is a function type; this plan defines exactly one, `WithClock(Clock)`
(see `clock.go` in Task 2), so plan 03-03's TCP timers are injectable without changing
this constructor.

**Dispatch seam (load-bearing for wave 2's parallelism).** Declare an unexported
interface — one method taking the parsed IPv4 source and destination addresses, the
transport payload slice, and the receiving attachment — and give `Stack` two fields of
that type plus two unexported registration methods (one for UDP, one for TCP), each
guarded by `mu` and each returning an error if a handler is already registered. This
plan registers neither: with both nil, UDP and TCP packets are counted and dropped.
Plan 03-02 registers the UDP handler from inside `ListenUDP` (in `udp.go`); plan 03-03
registers the TCP handler from inside `ListenTCP` (in `tcp_listener.go`). Write a comment
saying exactly that, so a later reader does not "simplify" the seam away and re-couple the
two files.

`Attach(sess Session, ip net.IP) error`: converts `ip` to a `netip.Addr`, rejects nil,
non-IPv4, and an address equal to the server tunnel IP (a session may not claim to be the
server); rejects a duplicate IP already in `routes` with a typed error; creates an
`attachment{sess, ip, stopCh, stopOnce}`, publishes it into `routes`, and starts
**exactly one** goroutine running `readLoop(a)`. Cite `Session.Read`'s single-reader
contract (session.go:305-313) in the doc comment and state that starting a second reader
would violate it.

`Detach(ip net.IP) bool` removes the route and closes the attachment's `stopCh` through
its `stopOnce` (the `session.go:95-106` discipline), so the read loop exits. It does NOT
call `sess.Close()` — the session's lifetime belongs to the embedder, not the stack.
Returns whether a route was removed.

`readLoop(a *attachment)`: allocates one `readBufferSize` buffer (2048, D-14 — see the
objective's rationale) and loops on `a.sess.Read(buf)`. **On any non-nil error it detaches
and returns** — this is the sole detach trigger (D-02). On success it copies
`buf[:n]` into a fresh slice before dispatch (the loop buffer is reused; handing the
shared array to another goroutine would be a data race) and calls `deliver`.

`deliver(a *attachment, pkt []byte)`: parse the IPv4 header. On a parse error, count and
drop. **Then, before any protocol dispatch, enforce two access-control rules and count
each drop separately:** (1) the packet's IPv4 source must equal `a.ip` — a session whose
packets claim another session's tunnel IP, or the server's own, is spoofing (T-03-01);
(2) the packet's IPv4 destination must equal the server tunnel IP — the stack is a
terminator, not a router, and forwards nothing (routing/NAT/forwarding is a stated
project non-goal). Only then switch on the protocol number: ICMP handled inline (below),
UDP and TCP handed to the seam fields if registered, everything else counted and dropped.

`writePacket(a *attachment, pkt []byte) error`: the single outbound seam every protocol
uses. It re-parses the packet it is about to send and **drops it, returning a typed error,
if the IPv4 source is not the server tunnel IP** (D-04, fail-closed — a bug that builds a
reply with the wrong source must not reach the wire). On success it calls `a.sess.Write`.
Document that `Write` is safe to call concurrently from timer goroutines and handler
goroutines (RESEARCH.md Pattern 4) so no lock is taken here.

`Stats() Stats` returns a snapshot of the atomic counters. `Stats` is an exported struct
with at minimum: `ICMPEchoRequests`, `ICMPEchoReplies`, `PacketsReceived`,
`MalformedDropped`, `FragmentsDropped`, `SpoofedSourceDropped`, `WrongDestinationDropped`,
`UnhandledProtocolDropped`, `OutboundSourceDropped`. These are the harness's observability
surface and the fast tier's assertion surface — every silent drop path above increments
exactly one of them.

`Close() error` detaches every attachment and closes `stopCh` once.

**`netstack/ipv4.go`.** File-level citation header naming RFC 791 §3.1 (header format) and
RFC 1071. Named constants with doc comments: `minIPv4HeaderLen = 20`, `maxIPv4HeaderLen =
60`, `defaultTTL = 64`, `protocolICMP = 1`, `protocolTCP = 6`, `protocolUDP = 17`,
`flagMoreFragments = 0x2000`, `fragOffsetMask = 0x1FFF`. Typed sentinel errors in
`internal/wire`'s style: `errTooShort`, `errNotIPv4`, `errBadIHL`, `errBadTotalLength`,
`errFragmented`.

`parseIPv4(pkt []byte) (ipv4Header, error)` returns a small struct carrying `ihl`,
`totalLen`, `protocol`, `src`, `dst` (`netip.Addr`), and `payloadOff`. Validation order,
each step before the next dereference: `len(pkt) >= minIPv4HeaderLen`; version nibble
== 4; `ihl := int(pkt[0]&0x0F) * 4` with `ihl >= minIPv4HeaderLen && ihl <= len(pkt)`;
`totalLen := binary.BigEndian.Uint16(pkt[2:4])` with `int(totalLen) >= ihl` and
`int(totalLen) <= len(pkt)`; the fragment check (`flags&flagMoreFragments != 0` or
`fragOffset != 0` → `errFragmented`). **IP options are skipped past, not rejected**
(RESEARCH.md Anti-Patterns, assumption A3): the payload starts at `ihl`, correctly
computed, so an IHL > 5 packet parses normally and its options are ignored. Do not verify
the inbound IPv4 header checksum — the packet already passed AEAD authentication below the
`Session` boundary, so a corrupted header is not a threat this layer adds value against;
say so in a comment rather than leaving the omission to be read as an oversight.

`buildIPv4(dst []byte, src, dstAddr netip.Addr, protocol uint8, payload []byte) []byte`
appends a 20-byte options-free header (IHL 5, DSCP/ECN 0, total length = 20+len(payload),
identification 0, flags/fragment 0, TTL `defaultTTL`, the given protocol, checksum
computed over the header with the checksum field zeroed) followed by the payload.
Emitting identification 0 with DF clear is correct here because this stack never
fragments and never relies on reassembly identity.

`internetChecksum(b []byte) uint16` — reproduce the RFC 1071 function byte-for-byte from
`test/interop/server/main.go:560-578` (already live-verified against a real client), with
a doc comment quoting RFC 1071's own "adjacent octets ... paired to form 16-bit integers"
sentence and noting the trailing-odd-byte rule.

`pseudoHeaderSum(src, dst netip.Addr, protocol uint8, length uint16) uint32` — the RFC 768
/ RFC 9293 12-byte IPv4 pseudo-header partial sum (src 4B, dst 4B, zero 1B, protocol 1B,

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Authenticated tunnel peer → `Session.Read` | Every packet here has passed AES-256-GCM authentication, so it is genuinely from *a* connected client — but nothing upstream constrains what that client puts *inside* the IP packet. This is the first layer that treats the payload as structured data. |
| `netstack` read loop → protocol dispatch | The point at which a client-supplied IPv4 header decides which code path runs; a bad IHL or length field here is the classic slice-bounds panic |
| One attached session → another attached session's flows | Multiple clients share one `Stack`; the IP→session route table is the only thing keeping their traffic apart |
| `netstack` → `Session.Write` | Bytes the stack constructs cross back into the encrypted tunnel; a wrong source IP here is the server impersonating a client |

## STRIDE Threat Register (ASVS L1 — block on high)

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-01 | Spoofing | `Stack.deliver` source-IP check | high | mitigate | The parsed IPv4 source must equal the `Attach`-registered IP for the session the packet arrived on; a mismatch is dropped before any protocol dispatch and counted in `Stats().SpoofedSourceDropped`. Asserted by `TestSourceIPSpoofDropped` for both the "claim another client's IP" and "claim the server's IP" cases. This is the netstack's own access-control boundary — nothing upstream enforces it (RESEARCH.md Security Domain, V4). |

| T-03-03 | Denial of Service | IPv4 fragment handling | medium | mitigate | Fragments are dropped silently with no reassembly buffer and no timer, so there is no per-attacker state to exhaust and no reassembly logic to attack.
